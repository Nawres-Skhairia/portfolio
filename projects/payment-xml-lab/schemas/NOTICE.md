# ISO 20022 schema files: notice

This folder holds two ISO 20022 message schemas, both served **unchanged**: `pain.001.001.09.xsd` and `pacs.008.001.08.xsd`.

`pain.001.001.09.xsd` is the ISO 20022 message schema for "Customer Credit Transfer Initiation", version 09,
as published by the ISO 20022 Registration Authority (https://www.iso20022.org/). It is served here **unchanged**
so that payment files can be checked in the visitor's browser.

## pacs.008.001.08.xsd

as published by the ISO 20022 Registration Authority (https://www.iso20022.org/). It is used by the MT to MX Migration Lab
to check the message it generates.
