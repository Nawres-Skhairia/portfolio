Traceability Hub

Consultants write the requirements, testers write the tests, and the link between them lives in a spreadsheet nobody updates. When a requirement changes, nobody knows which tests are now testing the wrong thing. This hub keeps requirement → test → result → defect in one live matrix, and flags stale tests the moment the wording changes.
